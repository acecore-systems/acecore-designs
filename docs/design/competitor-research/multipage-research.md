# 同業20サイト・サービス比較：ページ構成と図・イメージの活用

確認日: 2026-10-19（JST）。改修基点: `8d1c447695b46f14aa0fd099453f6207de4455e8`。

既存の[10社比較](research.md)を引き継ぎ、イラスト・3D・文章・音声の公式サービス10対象を追加した。合計は20サイト・サービスであり、20の独立企業を意味しない。CG MAKERS と VOICE MART は同じJPCのサービスである。Acecore Systems は自社の別枠参考とし、この20対象に含めない。

現行方針は、6件をAcecore Designsの**制作実績**として案内し、制作内容・成果物・対応サービス・法人相談を結ぶこと。個人サイトへの紹介を主目的にしない。作品内の制作者クレジットと朗読の原作者表記は保持する。未確認の顧客名、受注経緯、売上・満足度・改善率などは加えない。

## 確認方法と限界

- 既存10対象の公式本文・リンク構造・条件は2026-10-18の記録を再利用した。全社を2026-10-19に再調査したという意味ではない。
- 追加対象は2026-10-19に公式ページの本文とリンクを確認した。取得本文に画像の存在やaltがあっても、画像そのものを見た証拠とは区別する。
- 追加対象のうちCG MAKERS、Sunbird、Gugenka、EWSの4対象をBrowser/IAB、1036×720で確認した。CG MAKERS・Sunbird・Gugenkaは実画面で画像の役割も確認した。EWSの画面確認は最初の表示範囲に限り、下の作品画像の配置は実見していない。Sunbird・Gugenkaは本文抽出が空でもIABでは表示できたため、取得不能と画面未確認を混同しない。キャラクリエは本文・リンクの確認にとどまる。
- オムカレーは直接取得が繰り返しtimeoutとなった。公式URLを指定した検索抽出で制作実績と会社案内の本文を確認した。実画面の配置・画像・操作については断定しない。
- 競合の問い合わせ送信、資料登録、発注、見積ツール操作は行っていない。音声品質・制作物品質の優劣、問い合わせ増加、成約率は評価していない。今回の採否は情報設計の判断である。

## 図・イメージの採否

| 表現の役割             | 比較から得た判断                                                     | Designsでの実装                                                                                     |
| ---------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 完成イメージ・作品画像 | CG MAKERS・Sunbird等は、作れる表現を大きい画像で示す                 | 確認済みの実画像4点をトップ・分野詳細・実績で再利用。構図全体を表示し、架空作品を追加しない         |
| 入力と成果物の対応     | Gugenkaの原画と3Dは対応する素材があるから成立する                    | 分野別に「相談材料→制作→成果物」をHTMLの順序リストとSVG矢印で図示。対応原画のない擬似比較は作らない |
| 進め方                 | CG MAKERS・BraveryStudio・ナレーション工房は制作前の確認も説明する   | 既存の4工程を矢印で接続し、トップには要約、工程ページには準備物・FAQも掲載                          |
| 文章・音声の確認       | オムカレー等は担当範囲を文字で伝え、音声サービスは試聴を別に案内する | 小説は本文公開先、朗読は既存YouTubeへ案内。装飾アイコンを実物サンプルとは呼ばない                   |
| プラン比較・数値図     | 条件が異なるプランや価格例は単純比較できない                         | 自社13件の開始料金と正本文のみ。独自の価格差・納期・効果のグラフは作らない                          |

図は画像化せず、見出し・本文・順序リストで読める構造にした。矢印は装飾として読み上げ対象から外し、画面が狭い場合は縦方向に並べる。各分野の内容は次のとおり。

- イラスト: 用途・イメージ・既存キャラクター・参考資料 → 設計／描画・設定資料制作 → キャラクター・表紙・挿絵・設定画。
- 3D: 用途・使用環境・既存モデル・参考資料 → モデル制作／調整／演出 → キャラクター・小物・表示切替等の機能。
- 文章・音声: テーマ・設定・企画／収録用の支給原稿 → 物語・台本の執筆／支給原稿の読み上げ収録 → 文章／音声データ。執筆と収録を必ず一括提供するように見せない。

どの図もサービスによって経路が異なり、範囲と納品形式は見積時に確認する旨を併記する。画像の出典と取得日は[既存ソースデータ](../../../src/data/portfolio.mjs)、制作内容とクレジットは各言語UIの記録を維持する。追加の画像取得・生成、第三者作品のコピー、新しい依存ライブラリはない。

## 採用したページ構成

総合案内、比較、制作物の確認、相談準備は目的が異なる。すべてをトップ内の移動に任せる構成から、次の8種類へ分けた。一方、13サービスの本文は短く、個別素材や固有FAQがそろっていないため、13個の詳細ページは作らない。

| ページ                     | 掲載内容と次の行き先                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `/`                        | 既存ヒーロー文＋実作品、3分野への入口、代表実績、料金と工程の入口、法人相談     |
| `/services/`               | 3分野の比較、用途から13サービスへの索引                                         |
| `/services/illustration/`  | 入力・制作・成果物の図、6サービスの正式内容・価格・相談、関連実績               |
| `/services/3d/`            | 3D固有の図、4サービス、関連実績                                                 |
| `/services/writing-audio/` | 執筆と支給原稿の収録を分けた図、3サービス、小説・朗読実績                       |
| `/works/`                  | 6件の制作内容・成果物・クレジット・出典、対応サービスと `offering` 付き法人相談 |
| `/pricing/`                | 13件すべての正本文と税込開始料金、詳細と個別相談                                |
| `/process/`                | 4工程、6つの相談材料、既存本文に基づく4FAQ、研修・支援の案内                    |

日本語と8翻訳で同じ構造を持つ。主ナビとフッターはサービス・実績・料金・工程の別ページへ進む。サービスカード・実績には補助のアンカーを使う。パンくず、言語切替、canonical、hreflang、x-default、OG、構造化データは現在ページを参照する。サイトマップは72の通常ページを列挙し、9つのエラーページを除外する。

旧トップの `#catalog` は料金、`#works`・`#creator` は実績、`#flow`・`#faq` は工程、各サービスIDは該当分野ページ内のサービスへ移す。クエリは保持する。JavaScriptが無効でも主ナビを表示し、トップに13サービスへのリンク一覧を用意する。未知・不正なhashから外部転送は行わない。

## 維持した内容と検証

- `src/content/catalog` の9正本、13件の正式名称・説明・数値料金・範囲を変更しない。画面と構造化データは同じ正本を参照する。
